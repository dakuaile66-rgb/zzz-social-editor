# AI 工具管理與跨工具交接

參考：mars-tw/ai-console 的本機 AI 工作臺與有限背景交接概念。此處僅整合流程，沒有安裝 AI Console，也不宣稱 ChatGPT 能自動同步所有平台。

## 專案素材交接
1. 企劃：核心梗、角色來源、玩家脈絡與目標平台
2. 參考素材：角色母版、頭幀／尾幀、原片、鏡頭時間碼
3. AI 生成：模型、平台、Prompt 版本、參考輸入、審核結果
4. 後製：剪輯版本、字幕語言、音效與音樂授權來源
5. 發佈：平台、審稿、日期、描述文案
6. 回顧：完播、觀看、互動、Organic/Paid 區分與失敗原因

## 最小交接卡（每個鏡頭）
- 專案／集數／鏡頭 ID：
- 角色及最新母版版本：
- 使用模型與平台（例：Artlist 的 Seedance 2.5）：
- 參考影片用途（運動／構圖／時間／環境）：
- 頭幀／尾幀：
- 固定條件：
- 已知問題／本輪修正：
- 下一個動作：
- 產出位置／版本：

## 工具邊界
- AI Console 若使用，需另外依官方 README 安裝及配置；本 Repo 無自動安裝、背景派工、遠端同步或模型能力保證。
- 不在 GitHub 提交帳密、API Key、未授權素材或私人對話。
- 不讓外部工具敘述覆蓋人物設定及平台的實際限制。

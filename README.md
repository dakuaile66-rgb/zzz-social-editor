# zzz-social-editor

《絕區零》二創社群內容工作知識庫。

這個 Repo 不是官方素材庫，也不是泛遊戲社群模板；它是給「《絕區零》玩家向二創帳號」使用的固定工作手冊。

## 核心定位
- 非官方帳號
- 玩家向二創
- 內容以角色梗、劇情誤會、社死、反差、迷因、AI 二創為主
- 不追求把劇情講完整，優先放大玩家會懂、會笑、會留言的點
- 先理解「玩家為什麼會笑」，再決定怎麼寫、怎麼剪

## ChatGPT 在這個專案的角色
1. 二創企劃
2. 玩家語氣文案
3. 剪輯導演／逐秒剪輯表
4. 社群排程助手
5. 成效分析助手
6. 工作流自動化助手

## 目錄
- `style/`：玩家口吻、平台文案、禁用語氣
- `zzz/`：角色、梗、世界觀、二創脈絡
- `editing/`：剪輯規則、卡點、參考風格、失敗紀錄
- `examples/`：成功／失敗內容案例
- `hooks/`：可複用開頭與鉤子
- `workflow/`：從題材到發布的 SOP
- `analytics/`：成效欄位與判讀規則
- `tools/`：WhisperX、pyannote、PySceneDetect、Auto-Editor、Remotion、n8n
- `prompts/`：AI 視覺／影片提示詞規則

## 最高優先規則
如果新規則與舊規則衝突，以「使用者最新明確回饋」為準。

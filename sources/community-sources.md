# 固定社群觀察來源

這份清單用來建立《絕區零》玩家語感、角色梗、近期迷因與短影音題材庫。

## 高優先來源

### X — @ZZZnew_meme
- URL: https://x.com/ZZZnew_meme
- 使用者明確表示很常看
- 用途：近期迷因、角色梗、文案節奏、玩家接梗方式
- 備註：完整時間線可能受 X 登入／抓取限制；單篇連結可提高分析準度

### YouTube Shorts — bangboo先生
- URL: https://www.youtube.com/@bangboo先生/shorts
- 用途：短影音梗題型、標題／開頭結構、節奏、角色迷因、近期熱門題材
- 公開索引可看到近期持續發布《絕區零》meme／小ネタ／shorts 類內容
- 適合作為「短影音二創」高權重參考

### NGA《絕區零》版
- URL: https://bbs.nga.cn/thread.php?fid=853&rand=434
- 用途：深度角色梗、版本內黑話、長討論串、玩家共識
- 備註：站方可能限制直接抓取；重要討論最好提供單篇連結或截圖

## 中高優先來源

### HoYoLAB — 絕區零搜尋
- URL: https://www.hoyolab.com/search?keyword=絕區零
- 用途：官方社群氛圍、角色實裝反應、活動梗、官方社群可接受的玩家語感
- 備註：搜尋頁不一定能完整抓取

### Facebook 社群
- URL: https://www.facebook.com/groups/1353266628722704
- 用途：台灣玩家語氣、在地用詞、留言接梗、熱門角色話題
- 備註：Facebook 社團常有登入／成員權限限制；單篇貼文或截圖更可靠

## 廣泛觀察來源

### X hashtag — #ZenlessZoneZero
- URL: https://x.com/hashtag/ZenlessZoneZero?src=hashtag_click
- 用途：國際圈近期角色熱度、英文圈迷因、跨語言梗
- 不將單一貼文直接視為玩家共識

## 收錄規則
1. 使用者明確指定常看的來源，權重最高
2. 一個梗至少交叉看多個貼文／留言再視為玩家共識
3. 不照抄單一創作者文案
4. 要提煉：角色共識、笑點結構、常用稱呼、接梗方式
5. 明顯過時或只在單一圈層流行的詞，需標記
6. 若來源無法直接抓取，改用單篇連結、截圖或使用者提供文字
